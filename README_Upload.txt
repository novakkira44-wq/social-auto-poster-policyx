SOCIAL MEDIA AUTO POSTER – GITHUB PAGES
======================================

This ZIP contains ONLY the public informational website, NOT the app.

1. Extract the ZIP.
2. At github.com/new create a PUBLIC repository named social-auto-poster-policy.
3. Select Add a README, create the repository.
4. Inside the repository, choose Add file > Upload files.
5. Upload these 5 files from this folder (not the ZIP itself):
   index.html, privacy.html, terms.html, deletion.html, style.css
   (the README file itself is optional).
6. Commit changes.
7. Repository > Settings > Pages > Build and deployment
   Source: Deploy from a branch
   Branch: main, Folder: /(root) > Save.
8. Wait for publishing, then open your Pages site.

Example URLs (replace YOUR_GITHUB_USERNAME):
https://YOUR_GITHUB_USERNAME.github.io/social-auto-poster-policy/privacy.html
https://YOUR_GITHUB_USERNAME.github.io/social-auto-poster-policy/terms.html
https://YOUR_GITHUB_USERNAME.github.io/social-auto-poster-policy/deletion.html

In Meta App Settings > Basic:
- Privacy Policy URL: .../privacy.html
- Terms of Service URL: .../terms.html
- User data deletion: Data deletion instructions URL > .../deletion.html
