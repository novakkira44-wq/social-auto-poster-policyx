Privacy Policy

Last updated: October 21, 2026

Social Media Auto Poster ("the App") is a local Windows application operated privately for the management and authorized publication of social-media content. For questions about this policy or data processing, contact novakkira44@gmail.com.

1. Information processed

When the App is used, it may process Facebook Page identifiers and names; linked Instagram account identifiers and usernames; access tokens granted by Meta; selected video files; captions and hashtags; optional story URLs and labels; content classification such as whether a video is AI-generated; planned publishing settings; and publication results, identifiers and error messages.

2. Purpose of processing

Data is processed only to identify authorized accounts, organize video content, prepare posts, publish selected videos through the Meta APIs, display upload results, and provide local publishing history. The App does not sell personal data or use it for targeted advertising.

3. Local storage and security

The App runs on the user's Windows computer at 127.0.0.1. Imported media and a local SQLite database are stored in its data folder. Facebook Page access tokens obtained through authorization are stored in the local database using Windows Data Protection API (DPAPI) encryption, associated with the Windows user. Users should protect access to their Windows session and back up their data securely.

4. Sharing with external services

When publishing is requested, the relevant account identifiers, necessary permissions, video and caption are sent to Meta's Facebook and/or Instagram services for processing and publication. Their data handling is subject to Meta's applicable policies. The App's public information pages are hosted on GitHub Pages; visiting this website can result in technical connection data being processed by GitHub in accordance with GitHub's policies.

5. Retention

Local videos, account connections and publishing history are kept on the user's device until the user deletes those items or removes the application data folder. Revoking a Meta authorization may prevent further API use but does not automatically erase existing local video files or records. Posted content remains on Meta platforms until separately removed there.

6. Your choices and rights

Users can stop using the App, disconnect Facebook/Instagram authorizations, delete local data and request assistance using the contact address above. See Data Deletion Instructions for the exact steps. Requests concerning rights under applicable privacy law can also be sent to that address. The App's operator may not have remote access to data held exclusively on the user's personal computer.

7. Children

The App is not directed to children. It is intended only for users eligible to use the relevant Meta platforms and developer services.

8. Changes

This policy may be updated when the App's features or data practices change. The date at the top identifies the latest published version.
