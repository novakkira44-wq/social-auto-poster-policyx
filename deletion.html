Data Deletion Instructions

Last updated: October 21, 2026

If you would like to remove your account connection or data associated with Social Media Auto Poster, follow these instructions. For assistance, contact novakkira44@gmail.com with the subject Social Media Auto Poster — Data Deletion. Never email access tokens or passwords.

1. Disconnect authorization from Meta

  1. Open Facebook or Meta's settings for connected apps/business integrations using the same account that authorized Social Media Auto Poster.
  2. Locate Social Media Auto Poster and remove its authorized access, where available.
  3. If necessary, revoke or regenerate affected access tokens through Meta for Developers.

2. Remove data stored on your computer

  1. Close Social Media Auto Poster and stop its local Python process.
  2. Open the application's Social_Auto_Poster folder on your Windows computer.
  3. Delete the data folder to remove the locally saved video files, account connection records, encrypted tokens, captions/links saved in the local database, publishing history and schedules. Make a backup first if you want to retain any files.
  4. Optionally delete the remaining application folder to uninstall the utility.
Important: Deleting the local data folder does not delete Reels, Stories or posts already published on Instagram/Facebook. Remove those separately on the relevant platform.

3. Contact / deletion requests

For a request about any information that the operator may hold outside the local application, email novakkira44@gmail.com, identifying the relevant account without disclosing passwords or access tokens. Requests will be reviewed and responded to in accordance with applicable law. Because the utility stores most data only on the user's own device, the operator may not be able to delete files stored exclusively on that device remotely.

4. Public policy website

This page does not provide user accounts or accept uploaded files. Hosting of these pages is provided by GitHub Pages; GitHub may separately process technical website access information under its own privacy policies.
